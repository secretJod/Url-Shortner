# URL Shortener

### a developer's own field notebook

**Go + Fiber · React · PostgreSQL · Redis · Docker · nginx · GitHub Actions · Prometheus + Grafana**

---

**How to read this book.** Read one chapter, close it, and explain it out loud in thirty seconds.
Every major topic ends with an ★ interview tip — a question someone would actually ask, and the
answer in your own words. Every fact in here is cited to a real file in this repository — nothing
here is invented behavior.

Four parts, twenty-seven chapters:

1. **Setup & Architecture** (ch. 1–7) — the map, the stack, Docker explained from zero, and how
   to stand this whole thing up on a machine that has never seen it before.
2. **Backend & APIs** (ch. 8–15) — every endpoint, two full request traces, and the four real
   optimizations this system makes, each told as a problem it solves.
3. **Frontend & the User Journey** (ch. 16–20) — the component tree, how the UI and the backend
   actually talk, and one continuous story from a stranger's first visit to their dashboard.
4. **Monitoring & Deployment** (ch. 21–27) — nginx, metrics, the real CI/CD pipeline, and the
   honest story of what actually happened getting this deployed — including the parts that broke
   first.
